① 現在のあべし数（経過ゲーム数）

まだ当選していない現在のゲーム数を入力・更新すると②③④⑤がリアルタイムで再計算されます。当選したら登録ボタンで履歴に記録し、現在のゲーム数を0に戻します。

⚠ 想定データ範囲を超えています。参考値は均等表示になります。
天破の刻 突入回数 0
詳細入力（G数・設定変更）

実機のG数カウンター（あべしとは別の、リセットされない累計値）です。登録すると⑦設定判別に使われます。登録時に所持枚数の確認ウィンドウが開きます。天破の刻突入回数は台移動までリセットされず、⑦設定判別に使われます。

電源の入れ直し（リセット）だけでは天井G数・内部状態・有利区間は引き継がれ、短縮されません。短縮天井が働くのは実際に設定変更があった場合のみです。「今日の1G目から打っている」というだけではチェックしないでください。短縮天井は最初の1サイクルのみ有効なため、あべし成立を記録すると自動でチェックが外れ、通常の天井に戻ります。

あべし数の進行にあわせて、天国ライン(128G)→モードCライン(576G)→モードBライン(896G)→モードA・真の天井の順に、次に超えるべきラインまでの残りゲーム数を表示します。37〜38G・43〜45Gはシャッター演出が出やすい区間としてモードCを示唆します。

⬜ 1473あべしを超えて当選（直撃でもWIN表示時点で超えていればOK）→ ATレベル3以上濃厚

攻略サイト（nana-press.com）の期待値計算に基づく狙い目ラインです。当ツールの「①現在のあべし数」とそのまま比較しています。

③ 現在の推定状態

実測のモード移行率を初期確率とし、「その回数まで当選していない」という事実を反映して都度再計算しています（過去の当選履歴そのものの積み上げではありません）。

④ やめ時サイン

-
--%

所有枚数 = 投資額（円→メダル換算） + 獲得枚数合計 − （①「現在のG数」×3枚）で自動計算します（G数未登録の場合はあべし履歴からの概算G数を使用）。投資額を追加した時・G数の登録時・獲得枚数の入力/編集時に再計算されます。差枚数欄は手動で書き換えても構いません。

576G＝モードC消滅、896G＝モードB消滅（以降モードA確定）という実際の壁に沿って「やめ時濃厚」ゾーンを判定し、天井が十分近づいたら「天井狙い推奨」に切り替えます（獲得枚数の記録があればそこから計算した平均獲得枚数、なければ天井の80%地点を目安に使用）。差枚数が大きくマイナスの場合はそれより早く「やめ時濃厚」を出します。

⑤ 次あべし当選ゲーム数（有力レンジ TOP3）

現在のゲーム数より後のレンジのみを対象に、③の推定状態を踏まえて算出しています。

⑥ ゾーン外プレ前兆チェック

37〜48G・166〜173G・288〜300G・421〜429G・489〜495Gの5区間で、レア役を引いていないのに前兆演出が出た場合は「896G以内当選濃厚（モードB以上）」の目安になります。①のゲーム数がこの区間に入ると下に確認ボタンが表示されます。

各モードの規定あべし上限・データ出典について

通常A＝〜1536G／通常B＝〜896G／通常C＝〜576G／天国＝〜128Gが規定あべしの上限です（この範囲を超えて未当選なら、そのモードである可能性はほぼ消えます）。

③④⑤の推定には、あべし成立時の「次モード移行率」（設定1・通常時：A51.9% B23.7% C17.6% 天国6.8% ／ 設定変更時：A49.3% B22.0% C20.1% 天国8.6%）を新しい区間の初期確率として使用しています。⑥ゾーン外プレ前兆の判定は攻略サイトの経験則に基づく目安で、③④⑤の数値計算には含めていません（⑥で判定を記録した場合、④の表示にのみ目安として反映します）。

当初ご指定の「37〜38G・43〜45GでモードC示唆」は、調査の結果おそらくこの37〜48G区間（モードA以外全般を示唆）の簡略版と考えられます。

設定差・ATレベルについて（参考情報）

設定示唆：筐体中央ランプ金点灯／両サイドランプ紫点灯・点滅／サミートロフィー虹色→いずれも設定6濃厚〜確定。

ATレベル：AT当選時にLv1〜4が決定し、AT終了まで固定。レベルが高いほど、各セット開始時の闘神レベル（A〜D、Dが最上位）が優遇されます。オーラ色は白→青→黄→緑→赤→紫→虹の順で期待度が上がります。

天井期待値の目安・AT終了後のヤメ時（参考情報）

nana-press.comの期待値シミュレーションより（設定1基準・「1G消化＝1.5あべし」という同サイト独自の換算を使用した参考値。実際のあべし増加は1G＝1あべしのままです）。

通常時・等価交換：300G -98円 → 350G +214円(転換) → 500G +1,424円 → 750G +4,795円 → 900G +8,103円

通常時・5.6枚交換：400G -548円 → 500G +303円(転換) → 750G +3,649円 → 900G +6,934円

リセット時・等価交換：300G +332円(転換) → 600G +3,903円

リセット時・5.6枚交換：400G +188円(転換) → 600G +2,853円

AT終了後のヤメ時：基本は即ヤメ。余裕があれば128あべしまでフォロー（天国濃厚）、余剰分が多ければ256あべしまでフォロー（ゾーン対象）。天撃失敗後は天国濃厚のため、必ずAT当選まで続行すべき。

AT中のバトル・演出について（参考情報・通常時の判断には未使用）

このツールは主に通常時（AT当選前）のモード予想を目的としているため、以下はAT当選後の参考情報として記載するのみで、③④⑤⑦などの計算には組み込んでいません。

闘神演舞［AT］：初期30G/セット、純増約4.0枚/G。セット開始時の闘神レベル（A〜D）ごとに勝舞魂の獲得しやすさ・奥義発動率・上乗せ個数の振り分けが異なります。百裂カットイン出現率1/1236.5、神拳BAR揃い1/1927.5（このとき期待度64.2%）。

神拳勝舞［継続バトル］：1戦あたりの勝利期待度は約1/5、純増約4.0枚/G。継続ゲーム数＝勝舞魂の所持数に依存。対戦する敵キャラによってトータル勝率が大きく異なり（シン8.8%〜ジャギ88.3%）、レイ・トキ登場は勝利濃厚とされています。

SPバトル特闘／EXバトル極闘：特闘の継続率は77%・80%・90%の3種類があり、特闘後に極闘へ進むと継続率90%濃厚。極闘は90%ループのみで、1回の継続は9G。

天破の刻の突入率（内部状態・成立役別、通常時の参考値）：低確滞在時は弱チェリー/スイカ成立で0.8〜4.7%（設定1→6）、チャンス目/勝舞揃いで2.0〜6.3%。高確滞在時は全設定共通でスイカ31.3%・弱チェリー66.4%・チャンス目以上100%。強チェリーは内部状態を問わず25.0%、確定チェリーは100%。ただし「今どの内部状態にいるか」自体が観測できないため、このツールの⑦設定判別には現状組み込んでいません。

⑦ 設定判別（AT初当たり確率＋天破の刻）

①の「現在のG数」登録と「天破の刻 突入回数」カウンターを使って計算します。G数未登録の場合は①のあべし履歴から概算します。

総ゲーム数と、AT当選回数（履歴件数）・天破の刻突入回数の両方から実戦確率を計算し、公表されている設定1〜6の数値（AT初当たり1/366.0〜1/273.1、天破の刻1/100.2〜1/81.3）とどれだけ近いかをベイズ推定・統合しています。事前確率は均等と仮定した簡易推定で、サンプル数が少ないと大きくブレます（目安として1000G・当選3回以上が最低ライン）。

⑧ ランプ示唆チェック

通常時は100G消化ごとにいずれかのランプが発光します。発光した色・パターンを選ぶと示唆内容が表示されます。消灯時は判断材料なしとして扱ってください。

小役・レア役の入賞時、通常とは違う色のLEDが光ることでAT前兆を示唆することがあります。成立した役と光った色を選ぶと示唆内容が表示されます。

参考情報：非前兆中に第3停止で告知演出が頻発する場合、高確率滞在の可能性が高くなるとされています。ただし出典元も「発生＝高確率滞在濃厚とはならない」と注記しており、具体的な信頼度%も公表されていません。あくまで参考程度に。
